## 그림 규칙

모든 그림이 한 덱처럼 보이도록 지킨다.

- **크기**: 1920×1080 기준(16:9). PNG는 2배(3840×2160)로 뜬다.
- **이미지 안에 제목을 넣지 않는다** — 슬라이드 제목이 따로 있다.
- **색은 역할 셋에만 쓴다.** 같은 색이 그림마다 같은 뜻이어야 범례 없이도 읽힌다.

  | 역할 | 선 | 채움 |
  |---|---|---|
  | AI가 판단하는 부분 | `#2563EB` | `#EFF6FF` |
  | 규칙(코드)이 통제하는 부분 | `#475569` | `#F1F5F9` |
  | 사람 | `#0F766E` | `#ECFDF5` |
  | (강조) 증상·이상 | `#DC2626` | `#FEF2F2` |

  빨강은 역할이 아니라 **"여기가 문제다"**를 가리킬 때만 쓴다.

- **글꼴은 맑은 고딕**, 굵기는 Regular·Bold 둘만(맑은 고딕에 중간 굵기가 없다).
- **대상 시스템과의 연결은 항상 위로 향하는 한 방향 화살표 + "읽기만"** — 이 시스템의 성질을
  그림마다 같은 기호로 보인다.
- 사내에 없는 예시는 쓰지 않는다.

## 파일 쓰는 법

| 파일 | 용도 |
|---|---|
| `images/*.png` | 슬라이드에 그대로 붙인다 |
| `images/*.svg` | PPT에 삽입 → 우클릭 **도형으로 변환**하면 글자·상자를 직접 고칠 수 있다. 맑은 고딕으로 그려진다 |

PNG는 맑은 고딕이 없는 환경에서 떴기 때문에 **대체 글꼴(Noto Sans KR)로 그려져 있다**. 모양과
폭은 거의 같지만, 맑은 고딕 그대로가 필요하면 SVG를 PPT에 넣어 쓰거나 PPT에서 그림으로 저장한다.
