## 규칙

- **대상 시스템에 쓰지 않는다.** 위 목록에 있는 것만 부를 수 있고, 전부 읽기다.
- **이번 라운드는 "무엇이 있는지 찾는" 라운드다.** 컬렉션·토픽·키 이름을 아직
  모르므로, 이름을 인자로 받는 읽기는 **다음 라운드에 낸다.** 지금 찍어서 부르면 빈
  결과가 오는데, 그건 "데이터가 없다"가 아니라 "질문을 잘못했다"이고 둘은 다른 사실이다.
- 가설은 **둘 이상** 세워라. 하나면 그것만 확인하고 조사가 끝난다.
- 태스크 하나는 **읽기 하나**다. 여러 번 읽어야 하면 태스크를 여러 개로 나눠라.
- `priority`는 낮을수록 먼저다.
